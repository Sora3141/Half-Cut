Half/Cut

一本の線で、ぴったり半分に。

DAILY 1 / 5
SCORE 0

DAILY #1

0 / 500

    遊び方

    1. 図形を横切るようにスワイプすると、その直線で紙が二つに切れます。線は盤面の端まで伸びます。
    2. 二つの面積が 50 : 50 に近いほど高得点。切ったあとに理想の線（同じ角度でぴったり半分になる線）が出ます。
    3. 穴は面積に入りません。離れた島は全部まとめて半分にします。

    判定

      モード

      今日の5問
      日付ごとに全員同じ5問。難易度が1問ずつ上がります。1日1回、結果はシェアできます。
      エンドレス
      持ち点は誤差12%分。切るたびに誤差が引かれ（1回で最大6まで）、尽きたら終了。上手以上なら少し回復し、続けるとコンボ倍率がかかります。3枚ごとに難しくなります。
      練習
      ドラッグ中に比率が見えます。難易度を選んで、何度でも同じ図形を切り直せます。
