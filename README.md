# Half-Cut (50:50) — 面積二等分パズル

表示された図形を、**面積がちょうど半分（50:50）になるように分割する**ことを目指すパズルゲームです。
「NEXT SHAPE」で次々と新しい図形に挑戦できます。

## 🔗 リンク

- リポジトリ: https://github.com/Sora3141/Half-Cut
- デモ: https://sora3141.github.io/Half-Cut/

## 概要

- 図形を 2 つの領域に分け、面積差をできるだけ 0 に近づける。
- どれだけ正確に 50:50 へ分割できたかを判定。
- 次々に異なる形状へ挑戦。

## 使用技術

- HTML / CSS / Vanilla JavaScript
- **Canvas 2D** による図形描画・面積計算
