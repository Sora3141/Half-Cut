# Half/Cut — 一本の線で、ぴったり半分に。

カッティングマットの上の紙を、スワイプ一本で **面積 50 : 50** に切るパズルゲームです。

- デモ: https://sora3141.github.io/Half-Cut/
- リポジトリ: https://github.com/Sora3141/Half-Cut

## ルール

1. 図形を横切るようにスワイプ（ドラッグ）すると、その直線で紙が二つに切れます。線は盤面の端まで伸びます。
2. 二つの面積が 50 : 50 に近いほど高得点。切ったあと、同じ角度でぴったり半分になる「理想」の線が表示されます。
3. 穴の部分は面積に含みません。離れた島は全部まとめて半分にします。

| 判定 | 誤差 | 
| --- | --- |
| 神業 PERFECT | ≤ 0.3% |
| 見事 EXCELLENT | ≤ 1% |
| 上手 GREAT | ≤ 2.5% |
| 及第 GOOD | ≤ 5% |
| 未熟 MISS | > 5% |

得点は 1 問 100 点満点で、誤差 10% で 0 点になります。

## モード

- **今日の5問（デイリー）** — 日付から決まるシードで、全員が同じ 5 問に挑戦。難易度は 1 問ずつ上がります。途中でやめても続きから再開でき、結果は絵文字つきでシェアできます。
- **エンドレス** — 持ち点は誤差 12% 分。切るたびに誤差が引かれ（1 回あたり最大 6）、0 になったら終了。上手以上で少し回復し、続けるとコンボ倍率（最大 ×2.0）。3 枚ごとに難易度が上がります。
- **練習** — 難易度を選び、ドラッグ中に比率を見ながら何度でも切り直せます。

図形は 16 種類（多角形・星・ハート・ブロック文字・C 字・くし・穴あき・ドーナツ・複数の島など）を 5 段階の難易度に振り分けて生成しています。

## スマホにインストール（PWA）

ホーム画面に追加すると、アプリのように全画面で起動し、オフラインでも遊べます。

- **Android / Chrome**: タイトル画面の「ホーム画面に追加」をタップ（またはメニュー → アプリをインストール）
- **iPhone / Safari・Chrome**: 共有ボタン → 「ホーム画面に追加」（タイトル画面のボタンから手順を表示できます）

## 開発

ビルド不要の Vanilla JS（ES Modules）です。モジュールを使うので `file://` ではなくローカルサーバーで開いてください。

```sh
npm start        # http://localhost:5173
npm test         # ジオメトリと図形生成のテスト（Node 20+）
```

```
index.html
css/style.css
src/
  main.js       画面遷移・モード・入力・結果表示
  geometry.js   面積・重心・半平面クリッピング・理想線の計算
  shapes.js     難易度別の図形ジェネレーター
  renderer.js   Canvas 描画（マット・紙・切断アニメーション・サムネイル）
  scoring.js    判定・得点・デイリーの日付計算
  audio.js      Web Audio による効果音
  storage.js    localStorage ラッパー
  rng.js        シード付き乱数
sw.js                 Service Worker（オフライン対応）
manifest.webmanifest  PWA マニフェスト
icons/                アプリアイコン（icon.svg から PNG を生成）
tests/
```

Service Worker はアプリのファイルをネットワーク優先で取得するので、通常の更新ではキャッシュのことを気にする必要はありません。`src/` にファイルを追加・削除したときは `sw.js` の `APP_SHELL` を更新し、`VERSION` を上げてください。

面積はサンプリングではなく、各リングを切断線の半平面で Sutherland–Hodgman クリッピングして厳密に計算しています。
